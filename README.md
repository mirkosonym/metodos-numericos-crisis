## Descripción del Proyecto

**NUMERYXLABS** es una aplicación web desarrollada como Proyecto Final de la materia **Métodos Numéricos (INF-373)**.

El proyecto tiene como objetivo simular y analizar diferentes escenarios relacionados con:

- Abastecimiento de recursos.
- Variación de precios.
- Impacto económico.
- Conflictos sociales.
- Optimización de recursos.
- Modelos matemáticos aplicados a situaciones de crisis.

La plataforma implementa distintos métodos numéricos para resolver problemas reales mediante simulaciones interactivas y visualización de resultados.

---

## Escenarios Desarrollados

El proyecto incluye los siguientes escenarios:

- Escenario A: Optimización del abastecimiento y red de transporte.
- Escenario B: Predicción de precios mediante interpolación.
- Escenario C: Evolución temporal de recursos.
- Escenario D: Modelado de conflictos sociales.
- Escenario E: Optimización de distribución.
- Escenario F: Análisis de estabilidad del sistema.
- Escenario G: Simulación integral de crisis.
